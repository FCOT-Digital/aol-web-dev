# Fighting Fantasy Project

* Program a fighting fantasy game so that you practice Python.

`AI-o-meter: Full`

---

Fighting fantasy books are a quite particular combination of a game and book.
They can be played with nothing more than a pen and a pad of paper.
I've brought a few examples with me if you want to borrow one.

What you're going to do during tutorial is program a version using your growing Python skills.
This will use your ability to output text, collect input, track values, branch code, and test code.

You may use AI to generate code, explain how to do specific parts, or write the story.
You must read and understand any AI generated code before running it.
You must check any AI generated code carefully by testing it thoroughly before giving it to anyone else.

At the end of the half-term, we will play each other's games.
