# Fighting Fantasy Project

* Program a fighting fantasy game so that you practise Python.

`AI-o-meter: Full`

---

![The Wizard](../3y1/01_wizard.png)

Fighting fantasy books are a combination of a game and book.
They can be played with nothing more than a pen and paper.
I've brought a few with me if you want to borrow one.

During tutorial you're going to program a version using your growing Python skills.
This will use at least the following skills:
* output text
* collect input
* track values
* branch code
* test code

You may use AI to generate code, ask how to code specific parts, or write the story.
You must read and understand any AI generated code before running it.
You must check and test any AI generated code before giving it to anyone else.

At the end of the half-term, we will play each other's games.
